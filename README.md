# ศุกร์แล้วโว้ย! — Office Rush

เกมเว็บแยกจากเกมอื่น เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งไลบรารี

## วิธีเล่น

1. กด **เริ่มกะวันศุกร์**
2. ดูคำพูดและไอคอนของที่ขอเหนือหัวเพื่อนร่วมงานในฉาก
3. ใช้เมาส์หรือนิ้วลากไอคอนของจากกองบนโต๊ะไปวางบนเพื่อนที่ขอของนั้น
4. ทำให้ครบ 8 งานก่อนหมดเวลาเพื่อไปฉลองวันศุกร์
5. ถ้าไม่ทัน งานจะตามไปถึงวันเสาร์–อาทิตย์ ลองเคลียร์ให้ครบก่อนหมดเวลาด้วย
6. ของหมดให้แตะลังสำรองบนโต๊ะเพื่อเติมของ

เกมขยายเต็มหน้าจอมือถือและลากของด้วยนิ้วได้ มีเสียงประกอบและดนตรีสั้นที่สร้างในเกม เปิด/ปิดเสียงได้จากปุ่มมุมบน

## ขึ้น GitHub Pages

อัปโหลดไฟล์ในโฟลเดอร์นี้ (`index.html`, `game.js`, `styles.css`, `README.md`) ไปที่ repo ใหม่ของเกม โดยวาง `index.html` ไว้ที่ root ของ repo จากนั้นตั้ง Pages ให้เผยแพร่จาก branch `main` และโฟลเดอร์ `/(root)`

ชื่อเกม ตัวละคร และบทพูดเป็นเรื่องแต่ง เพลงฉลองสร้างด้วยเสียงสังเคราะห์ในเกม
